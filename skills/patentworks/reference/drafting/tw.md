# 起草知識:TW(台灣專利法／審查基準特有要點)

> 種子版本:高信心核心要點。實作中依專利審查基準補充。與 common.md 並用。多數撰寫慣例與 CN 相近(同屬中文圈、兩段式),差異列於下。

## 1. 專利類型
- **發明專利**(利用自然法則之技術思想之創作)、**新型專利**(物品之形狀、構造或組合;**須有圖式**;採形式審查不實質審查)、**設計專利**(物品外觀)。
- 新型僅保護有形物品結構;方法、組合物走發明。

## 2. 揭露要件(專利法 §26)
- 說明書應明確且充分揭露,使該發明所屬技術領域中具有通常知識者**能瞭解其內容並可據以實現**(對應 enablement)。
- 申請專利範圍(請求項)應**為說明書所支持**,並明確、簡潔。
- 摘要應敘明所揭露發明之概要。

## 3. 文件結構
- 說明書章節:**發明名稱 → 技術領域 → 先前技術 → 發明內容 → 圖式簡單說明 → 實施方式 → 符號說明**。
- 申請文件:說明書、申請專利範圍、必要圖式、摘要。
- 摘要:**以 250 字為原則**(中文);指定一代表圖。
- 發明名稱應簡明表示申請標的,不得冠以無關用語。

## 4. 請求項格式
- 獨立項 + 附屬項;附屬項須包含所依附項全部技術特徵並進一步限定。
- 可採**兩段式**(前言 + 「其特徵在於」特徵部分),亦可不分段直接撰寫。
- 句式與中文撰寫慣例同 CN(「一種…，其特徵在於…」「依申請專利範圍第1項所述之…」),用語「申請專利範圍第N項」而非「權利要求N」。
- 各請求項以單獨項次記載;附屬項得依附一項或多項(多項依附須擇一)。

## 5. 專利要件
- **新穎性**、**進步性**(非能輕易完成)、**產業利用性**。
- 優惠期(grace period):因特定事由(如出於申請人本意之公開)於申請前 **12 個月**內公開者不喪失新穎性/進步性(須符合法定情形)。

## 6. 法定不予發明專利之標的(§24)
- 動、植物及生產動植物之主要生物學方法(微生物學方法除外)。
- 人類或動物之**診斷、治療或外科手術方法**。
- 妨害公共秩序或善良風俗者。
- (智力活動規則、純資訊揭示、純美術創作等不具技術性者,實務上以不符發明定義處理。)

## 7. 圖式
- 黑白線條;標號(符號)須與說明書「符號說明」及實施方式一致;代表圖供公開公報使用。

## 待補
- 經濟部智慧財產局《專利審查基準》各章細節、電腦軟體相關發明審查基準、設計專利規範、TIPO 申請實務。
