# 起草知識:EP(EPC／EPO Guidelines 特有要點)

> 種子版本:高信心核心要點。實作中依 EPO Guidelines for Examination 補充。與 common.md 並用。

## 1. 可專利性框架(EPC)
- Art 52:發明須有技術性;排除(「as such」)發現/科學理論/數學方法、美學創作、智力活動與商業方法之規則、電腦程式、資訊呈現——僅當其作為「as such」時排除,具技術貢獻者可專利。
- Art 53 例外:違反 ordre public/道德、植物動物品種與主要生物學方法、人體之外科/治療/診斷方法。
- Art 54 新穎性(絕對新穎性,**無一般優惠期**;EPO 對自我揭露不寬容)。
- Art 56 進步性:採 **problem–solution approach**(確定最接近先前技術 → 客觀技術問題 → 是否顯而易見)。

## 2. 揭露與請求項要件
- **Art 83 充分揭露**:須使該領域技術人員能據以實施(sufficiency)。
- **Art 84 明確與支持**:請求項須 clear、concise,並**為說明書所支持**。
- **Art 123(2) 禁止增加標的(added matter)——極嚴**:申請後不得加入超出原始申請(整體)可直接無歧義導出的內容;中間概括(intermediate generalisation)風險高。撰寫時務必把各層級的概括與組合都寫進原始說明書。

## 3. 請求項格式
- **兩段式(Rule 43(1))**:preamble(已知特徵)+ **"characterised in that"**(特徵部分,區別於最接近先前技術)。
- 請求項類別:product / process / use / apparatus;一申請各類獨立項數受限(Rule 43(2))。
- 用 reference signs 加括號對應圖式(不限定範圍)。
- 附屬項以 reference 方式記載並進一步限定。

## 4. 單一性(Art 82 / Rule 44)
- 一申請僅一個發明或一組具單一總括發明概念(single general inventive concept)、共享 special technical features 的發明。

## 5. 說明書結構(EPO 慣例)
- Title → Technical Field → Background Art → Disclosure/Summary of Invention → Brief Description of Drawings → Detailed Description(實施方式/embodiments)→ Claims → Abstract。
- 須在背景技術指出最接近先前技術,並讓客觀技術問題可被導出(配合 problem–solution)。

## 6. 摘要與圖式
- Abstract:技術領域簡述,約 **150 字**為宜,供檢索用,無法律效力;指定一代表圖。
- 圖式:線稿、reference signs 與說明書一致。
