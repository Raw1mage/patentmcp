## 4. 證據強度與無效抗辯論述

### 4.1 證據力評估
*   **結論**：**[ 成功機率高 (Anticipation) / 進步性組合無效 (Obviousness) / 證據力偏弱 ]**
*   **主要論點**：
    *   前案 A 已公開了標的專利要件 1、2、4 的全部特徵。
    *   對於要件 3，前案 A 雖僅揭露 ANN，但結合前案 B 的 CNN 聲音應用，本領域技術人員在截止日前有強烈動機進行等效置換，以提升準確率，此置換並未產生任何非預期的功效。因此，標的專利 Claim 1 顯然不具進步性，應予無效。
