# Event: PatentDB Directory Structure Setup

## 需求背景
為累積本地專利庫、減少重複網路檢索成本，我們需要在 `patentmcp` 中建立一個 `patentdb/` 本地專利庫目錄。該檔案庫結構必須具備泛用性，能容納不同來源的資料格式（PDF、XML、JSON 元數據、附圖等）。

## 範圍 (Scope)

### IN
1. **建立 `patentdb/` 目錄結構規範**：
   - 設計一套以國別與專利號分層的泛用資料夾結構。
2. **建立專利資料庫的初始化與目錄結構產生邏輯**：
   - 提供工具或說明，規範如何針對特定專利號自動生成專屬目錄與空檔案架構。
3. **儲存規範定義**：
   - 在 `specs/patentdb-structure/` 下發布正式的專利庫結構設計規格書。

### OUT
- 本次暫不實作大量專利的批次同步與資料遷移邏輯，僅聚焦於「結構的建立與規範定義」。

## 任務清單
- [ ] 在 `specs/` 建立 `patentdb-structure/` 設計規格書。
- [ ] 在本儲存庫根目錄下建立 `patentdb/` 檔案庫，並放入一個範例專利（如 `TWI854998B`）的結構資料作為 Demo。
- [ ] 提交並結案。
