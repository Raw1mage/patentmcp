## Why (excerpt)

- **痛點**：
  1. 在前案檢索工作中，專案端需要手動或撰寫 Python 腳本（如 `build_charts.py`）對專利池進行國別、年份、CPC分佈等統計，並使用 Matplotlib 繪製統計圖表，重複性高且費時。
