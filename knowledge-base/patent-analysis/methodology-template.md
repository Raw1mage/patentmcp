# 得獎產業專利分析報告 — 通用方法論模板

> 蒸餾自 TIPO 產業專利分析與布局競賽 2021–2025 前三名 15 份報告書。
> 用途:當你要做一份專利分析報告時,這份是「照著做就有得獎骨架」的模板 + 工具箱。

---

## Part 1 — 通用文章架構(七段式骨架)

15 份報告共用同一套 TIPO 隱性範本。**任何一份得獎報告都可對應到這七段**,差別只在深淺、命名(第X章/壹貳參)與各段配重。

```
① 緒論 (Introduction)                              ~3–5%
   研究動機/目的 · 研究問題與方法 · 範圍架構流程 · 預期效益
   └ 進階:卷首放「評審意見↔團隊回應對照表」(2024/2025 多份採用,顯示迭代治理)

② 技術介紹與產業概況 (Tech & Industry Context)      ~15–20%
   研究標的界定 · 技術原理/分層拆解 · 主流產品 · 各國政策
   產業鏈(上中下游) · 市場規模 · 成本結構 · 技術路線圖
   └ 這段決定「技術軸怎麼切」,是後面功效矩陣的定義來源

③ 檢索策略與過程 (Search Strategy) ★必獨立成章      ~10–25%
   資料庫選定 · 關鍵字清單(多語同義字) · IPC/CPC 清單
   檢索式迭代歷程(初步式→多輪修正→最終式) · NOT 濾噪
   檢準率(Precision) · 檢全率(Recall) · 去重(檢索去重+家族去重)
   └ 這是競賽評分重點:方法論可複現性 = 名次分水嶺

④ 專利趨勢分析 (Patent Analytics) ★最長核心章        ~35–45%
   歷年申請趨勢 · 技術生命週期(S曲線) · 申請人分析(全球+各局)
   申請國/區域分析 · IPC 多階分析(三/四/五階交叉)
   技術功效矩陣(TF Matrix) · [進階]引證分析/主路徑/專利強度
   └ 巨觀(趨勢/申請人/IPC)→ 微觀(功效矩陣/核心專利/claim)雙層

⑤ 產業競爭力分析與發展策略 (Strategy)               ~10–20%
   PEST · 五力 · SWOT(+TOWS 矩陣) · 紅海/藍海策略
   專利布局策略(Granstrand 六模式) · 迴避設計 · 競爭力評分
   └ 必收斂到「台灣/本土企業該切入哪裡」的可執行建議

⑥ 結論與建議 (Conclusion)                          ~2–3%
   分對象輸出(政府/學研/廠商 或 決策者/研發者)

⑦ 附錄 (Appendix)
   核心專利清單 · 完整檢索式 · 參考文獻 · 出題企業會議記錄
```

**配重規律**:第③④章合計常佔 50–70%,是報告主體;④(專利趨勢分析)幾乎必為最長章。背景章(②)厚薄反映對「技術軸定義」的重視度。

## Part 2 — 方法論工具箱

分三層。**核心必備 = 15 份幾乎都有;進階加分 = 冠亞軍拉開差距的手法;策略層 = 收斂到建議的框架。**

### 2.1 核心必備工具(15 份公約數)

| 工具 | 做什麼 | 輸出 | 備註 |
|---|---|---|---|
| **歷年申請趨勢分析** | 逐年專利申請量,判斷產業熱度轉折 | 折線/長條圖(全球+分國) | 需注意 18 個月未公開期造成近 1–2 年數據失真,得獎報告會剔除 |
| **技術生命週期(S曲線)** | 申請量 × 申請人數 隨時間消長,判萌芽/成長/成熟/衰退期 | 散佈/氣泡圖 | 幾乎每份必做;可分技術/分國各繪一條 |
| **主要申請人分析** | 全球+各局前十/二十大專利權人排名 | 排名長條圖 | 進階:分申請人「屬性」(學研 vs 企業)、國籍 |
| **IPC 多階分類分析** | 三/四/五階 IPC 分布,交叉(全球×各局×歷年×前十大申請人) | IPC 分布圖/歷年趨勢圖 | 顆粒度是冠軍常見的深挖點(2023 輪胎近40張IPC圖) |
| **申請國/區域分析** | 專利在哪些國家/局布局 | 圓餅/長條/泡泡圖 | 常做「去除 CNIPA」版校正中國虛脹 |
| **技術功效矩陣(TF Matrix)** | 技術類別 × 功效類別 交叉,找技術熱點與空白 | 矩陣熱圖 | **技術分析的收斂點**,15 份幾乎全做;軸來自技術樹/魚骨圖 |
| **檢準率/檢全率評估** | 抽樣人工判讀驗證專利池品質 | 百分比+抽樣流程圖 | 已成標配;檢準率抽樣 1% 或固定樣本,檢全率以已知標的公司回推 |
| **檢索式迭代** | 初步式→多輪修正→最終式,NOT 濾噪 | 檢索式歷程表 | 每步附「專利數/檢索去重/家族去重」三欄 |

### 2.2 進階加分工具(拉開名次)

| 工具 | 做什麼 | 誰用過 | 為何加分 |
|---|---|---|---|
| **技術魚骨圖/技術樹** | 把技術拆成構面,作為功效矩陣的技術軸定義 | 2021手術機器人/2022氫燃/2023光阻/2024智能客服/2025顯示器 | 讓功效矩陣的分類「有依據」而非隨意 |
| **專利引證分析** | 前後引證關係,追技術傳承 | 2021雷射(引證圖)/2024智能客服(Top50文字雲)/2025顯示器(交互引證網絡) | 從「計量」下沉到「技術實質」 |
| **主路徑分析(Main Path, Pajek)** | 引證網路遍歷找技術演進主幹與關鍵專利 | 2021手術機器人/2023無線充電/2024 AR-HUD | 客觀挖「重要專利」取代主觀選案;需 Pajek 社會網路軟體 |
| **專利強度指標** | 技術廣度/深度/RTIC/RPA 等組合量化申請人強弱 | 2021車聯網(專利強度)/2023無線充電(4指標) | 把申請人強弱做成可比清單 |
| **量化競爭力評分模型** | 自建多構面×多指標,正規化加權算分排名 | 2022氫燃(6構面15指標+GNU Octave)/2023光阻/2025顯示器(7廠商評分) | **冠亞軍標誌**:競爭力從定性 SWOT 變可排名分數 |
| **claim 層級構型拆解** | 逐件讀獨立項,拆技術構型/流程 | 2021雷射(claim+引證+家族三連擊)/2024智能客服(ASR→NLU→DM→NLG→TTS)/2025 CAR(構型演進圖) | 接近 FTO/迴避設計實務,深度天花板 |
| **專利家族分析** | 查家族判斷 claim 擴充與國際化布局 | 2021雷射/2024智能客服(家族國際化) | 微觀個案手法 |
| **檢索品質 F1-measure** | 檢準率+檢全率的調和平均 | 2023無線充電(唯一) | 檢索評估最完整的一份 |
| **一手田野(會展/訪談)** | 實地訪談出題企業界定真實需求 | 2024 AR-HUD(唯一) | 方法論貼近業界,據此設計 NOT 表列 |
| **宏觀 vs 精準雙群體對照** | 廣域池 + 人工篩核心池,算占比聚焦度 | 2025 CAR(宏觀2002件 vs 精準109件) | 精準辨識真正核心玩家 |
| **白地/技術空白分析** | 專利密度低的技術空白區辨識 | 2023輪胎(隱含)/2025外泌體(專利密度+技術空白) | 少有正式命名章節,多以概念隱含 |

### 2.3 策略層框架(收斂到建議)

| 框架 | 用途 | 常見組合 |
|---|---|---|
| **PEST** | 政治/經濟/社會/技術總體環境 | 常與五力+SWOT 三件組並用 |
| **五力分析** | 產業競爭結構 | 針對本土標的企業 |
| **SWOT + TOWS 矩陣** | 優劣勢×機會威脅,推 SO/WO/ST/WT 策略 | 幾乎必備;TOWS 讓 SWOT 落地成行動 |
| **紅海/藍海策略(四行動)** | 降低/消除/提升/創造,找市場切入 | 2022氫燃/2023光阻/2024各份 |
| **紅/藍/灰海三區件數分區** | 用件數門檻切技術組合(授權/自研/居中) | 2024語音辨識(原創) |
| **Granstrand 六種專利布局模式** | 特定阻卻/圍牆式/包圍式/組合式/地毯式/策略式 | 2022/2023/2024 布局章常引用;萌芽期建議地毯式 |
| **CAGE 距離 + Go/Watch 決策矩陣** | 加權評分決定國別市場進入優先序 | 2025外泌體(嫁接管理學到專利布局) |
| **迴避設計(Design Around)** | 結合功效藍海+侵權風險提迴避方向 | 多份布局章 |

## Part 3 — 得獎名次的方法論分野

**骨架人人相同,名次差在這四個維度:**

1. **量化 vs 定性**:冠亞軍普遍多一層「可複現的量化」——自建競爭力評分模型(2022氫燃 GNU Octave、2023光阻、2025顯示器)、專利強度指標(2023無線充電)、CAGE 決策矩陣(2025外泌體)。季軍常以定性 SWOT 為主。
2. **深挖策略的選擇**:每份都有一條「招牌深挖線」——
   - 廣度+統計嚴謹:2021車聯網(2.7萬件池+抽樣檢準/檢全率)
   - 逐家精讀:2022鋰碳材(刻意不全量、人工讀十大申請人)
   - 引證網絡科學:2023無線充電/2024 AR-HUD(Pajek 主路徑)
   - claim 構型拆解:2021雷射/2025 CAR
   - 矩陣式平行:2025顯示器(四技術 × 全套手法)
3. **檢索方法論嚴謹度**:檢準率 < 檢準+檢全 < 檢準+檢全+F1;是否公開檢索式歷程、是否用已知公司做驗證錨點(2023光阻用 Inpria、2025 CAR 用開發中藥物回推)。
4. **企業問題驅動 + 落地**:得獎報告都以出題企業的真實痛點定義分析主軸,並把分析收斂成該企業可執行的決策(進入哪國、迴避哪件、自研哪塊),而非停在數據描述。

## Part 4 — 撰寫檢查清單(照抄可用)

做一份新報告時逐項打勾:

**檢索層**
- [ ] 選定資料庫(競賽指定 GPSS;實務可加 USPTO/EPO/Google Patents/DWPI)
- [ ] 多語同義字關鍵字表(中英日韓,涵蓋舊屬名/變體)
- [ ] IPC/CPC 清單(三階全涵蓋 vs 四五階聚焦,依需求切換)
- [ ] 檢索式迭代歷程表(每步附去重前後件數)
- [ ] NOT 負面表列濾噪(並前置 AND 回收誤刪)
- [ ] 檢準率(抽樣人工判讀)+ 檢全率(已知標的公司回推)
- [ ] 檢索去重 + 家族去重(雙重去重)

**分析層**
- [ ] 歷年申請趨勢(剔除未公開期失真)
- [ ] 技術生命週期 S 曲線(判產業階段)
- [ ] 主要申請人分析(全球+各局+屬性/國籍)
- [ ] IPC 多階交叉分析
- [ ] 技術魚骨圖/技術樹(定義功效矩陣的技術軸)
- [ ] 技術功效矩陣(技術×功效熱圖)
- [ ] [加分]引證分析/主路徑/專利強度指標
- [ ] [加分]核心專利 claim 層級拆解

**策略層**
- [ ] PEST + 五力 + SWOT/TOWS 三件組
- [ ] 紅藍海 或 Granstrand 布局模式
- [ ] [加分]量化競爭力評分模型
- [ ] 收斂到本土企業可執行決策

**治理層(競賽加分)**
- [ ] 卷首評審意見↔回應對照表
- [ ] 出題企業會議記錄
- [ ] 附錄公開完整檢索式(可複現)
