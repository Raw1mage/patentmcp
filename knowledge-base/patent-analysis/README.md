## 一句話結論

五屆 15 份得獎報告共用同一套 **TIPO 隱性範本**:`緒論 → 技術/產業概況 → 檢索策略(含檢準率/檢全率)→ 專利趨勢分析(趨勢+生命週期+申請人+IPC+技術功效矩陣)→ 產業競爭力與布局策略(SWOT/五力/PEST)→ 結論`,單一資料庫 **GPSS(TIPO)** 為指定檢索平台。**名次高低不在骨架,而在「深挖策略」與「量化/方法論嚴謹度」**——冠亞軍普遍多一層可複現的量化(競爭力評分模型、CAGE 決策矩陣、引證網絡),季軍常以單一深挖手法(claim 構型拆解、F1-measure、主路徑分析)取勝。
