## 0. 兩個平面：人類登入路徑 vs API 端點 (最重要的前置區分)

GPSS 有兩條技術平面，**語法支援度不同**，混用是踩坑根因：

| 平面 | 端點 | 布林/括號 | 切截 `*` | 鄰近 `[n,m]` | 額度成本 |
|---|---|---|---|---|---|
| **人類登入路徑** (gpss3 網頁) | `tiponet.tipo.gov.tw/gpss3/gpsskmc/gpssbkm` | ✅ 完整 | ✅ | ✅ | **不燒 API quota** |
| **API 端點** (REST) | `tiponet.tipo.gov.tw/gpss1/gpsskmc/gpss_api` | ✅ 布林 | ❌ 官方明載「API 布林檢索式不提供切截或字距運算」 | ❌ | 燒 quota + condition-length 硬閘 |

- **本表所有語法**以「九、檢索語法說明」為準，屬**人類登入路徑**能力全集。
- **API 端點閹割**：切截、鄰近運算在 API 端不提供；`gpss_api` 另受 condition-length 長度硬閘 (BR_20260715 根因) 與時段配額。
- **成本鐵律**：純檢索計數 / 取結果，**優先走網頁路徑省額度**；只有需 API 結構化回傳時才走 REST。

## 1. 核心語法：欄位限定的兩種語義 (務必分清)

GPSS 欄位限定有**兩種寫法，語義不同**：

### 1.1 模糊比對 (後綴 `@欄位`) — 含即命中

- 語法：`(關鍵字)@欄位`
- 語義：欄位**含有**該字詞即命中
- 例：
  - `(奈米碳管)@TI` — 專利名稱**含**奈米碳管
  - `(王)@AX` — 申請人名**含**「王」字：王曉明、鄭王富、簡聖王…

### 1.2 完全比對 (`欄位=值`) — 完全等於 / 帶頭

- 語法：`欄位=值`（`=` 後直接輸入，不加標點）
- 語義：欄位**完全等於**或**帶頭**該字詞
- 例：
  - `AX=王曉` — 申請人名**完全等於**「王曉」(不會找到王曉明、王晓天)
  - `AX=王*` — 申請人名**帶頭**為「王」：王一、王曉明…(不會找到鄭王富)

> **關鍵**：`(王)@AX`(模糊，含王)≠ `AX=王曉`(完全，等於王曉)。選錯語義=檢索結果全錯。

## 2. 布林邏輯與括號

| 能力 | 語法 | 說明 |
|---|---|---|
| 交集 | `Computer and network` | 同時含兩者 |
| 聯集 | `Computer or network` | 含任一 |
| 排除 | `Computer not network` | 含前者但不含後者 |
| 括號先運算 | `(電腦 or 計算機 or computer) and asia*` | 括號內先算 |
| **跨欄位布林** | `(bicycle)@TI NOT (battery)@AB` | **官方範例**：TI 含 bicycle 但 AB 不含 battery |
| **跨欄位檢索** | `(奈米碳管)@TI,CL` | 一次搜 TI + CL 兩欄位 (逗號分隔欄位代碼) |

> **這是「GPSS 布林足夠強」的核心證據**：`(...)@欄位` 可與 and/or/not 自由組合，跨欄位表達力等同 EPO CQL。

## 3. 片語 / 單字 / 數字

| 能力 | 例 | 說明 |
|---|---|---|
| 片語 (緊鄰) | `Medical education`、`奈米碳管` | 字詞完全緊鄰 |
| 片語 vs AND | `"medical AND education"` | 加 AND 則兩字可分開在不同位置 |
| 單一字詞保留 | `Vitamin B` | 查含 "Vitamin B"，不忽略單字 "B" |
| 完整數字 | `25000` | 找完整數字，不單查 2、5、0 |
| 半全形透通 | `3D` = `３Ｄ` | 半形/全形英數字檢索結果相同 |
| 特殊符號 | `7/11`、`100%` | 系統忽略特殊符號；`%` 為特例可查 100% |

---

## 4. 英文切截 (wildcards) — 僅人類路徑

| 類型 | 語法 | 命中例 |
|---|---|---|
| 截頭 | `*work` | network、rework |
| 截尾 | `Cent*` | cent、centenary |
| 截中 | `Col*r` | color、colour |
| 雙切截 | `Comput* net*` | — |
| 單字元問號 | `Col?r` | color (`?` = 恰一字元) |

> `*` = 任意字元數；`?` = 恰一字元。**API 端不支援切截。**

---

## 5. 日期查詢 (ID 欄位)

| 類型 | 語法 | 說明 |
|---|---|---|
| 等於 | `ID=2016` | 該年 |
| 介於 | `ID=20160101:20171231` | 區間 (冒號分隔) |
| 大於等於 | `ID=2016:` | 該年起 |
| 小於等於 | `ID=:201710` | 至該年月止 |

- 日期格式接受 `YYYY` / `YYYYMM` / `YYYYMMDD` 三種。
- **限縮用法**：把 `ID=20200101:20231231` 用 `and` 併入檢索式即完成日期限縮。

---

## 6. 鄰近運算 (`[n,m]`) — 僅人類路徑

| 語法 | 語義 |
|---|---|
| `computer [1,7] network` | network 在 computer 之後第 1~7 個字 |
| `computer [-3,2] network` | network 在 computer 之前 3 字至之後 2 字 |
| `computer [1,7] network [2,5] protocol` | 鏈式鄰近 (3 字需依序緊鄰) |
| `(電路[1,7]感測器)@TI` | 欄位限定鄰近 |
| `(電路[-5,3]感測器)@TI` | 前後範圍 |

**規則**：
- `n,m` 皆數字 (可正/負)，`m ≥ n`；必用半形 `,` 連結、`[ ]` 框起。
- 中文以 `[ ]` 兩邊的「字」為鄰近基準。
- 全形符號 `？；，、` 及半形符號會跳過計算；半形 `%` 為特例不跳過。

### 6.1 鄰近運算擴展

- 語法：`(電腦)[n,m](network or 網路)` — 只能以 `or` 串接，**不可用 and/not**。
- `[n,m]` 前後一定要有 `()` 且只能有一組 `[n,m]`。
- 例：`(筆電 or 電腦)[1,7](wifi or network or 網路)` → 擴展為 6 組鄰近運算。
- **上限**：擴展後 >25 組鄰近運算即不提供檢索。

## 7. 人名欄位開頭檢索 (`,_L`)

- 語法：`(WANG)@AX,_L` — 申請人 "WANG" **開頭**
- 語法：`(WEI)@IV,_L` — 發明人 "WEI" **開頭**

## 8. 欄位代碼表 (field codes)

從「表格檢索」的欄位帶入邏輯 (點「專利名稱」出現 `$TI`、點「摘要」出現 `$AB`)，欄位代碼：

| 代碼 | 欄位 | 代碼 | 欄位 |
|---|---|---|---|
| `TI` | 專利名稱 (title) | `AB` | 摘要 (abstract) |
| `CL` | 專利範圍 (claims) | `AX` | 申請人 (applicant) |
| `IV` | 發明人 (inventor) | `ID` | 日期 (date) |
| `IPC` | IPC 分類 | `CPC` | CPC 分類 |
| `DE` | 詳細說明 | — | (技術功效分析不含 DE) |

> 完整欄位代碼可於檢索頁點「代碼列表」查得；上表為常用集。
> **注意**：`@欄位` (模糊後綴) 用 `TI`/`AB`；`欄位=` (完全比對) 用 `AX=`/`ID=` 這種前綴等號式。

---

## 9. Stopwords 與資安禁用字元

- **Stopwords**：部分通用英文字為 stopword，無法當關鍵字檢索 (但結果顯示時正常呈現)。
- **資安禁用字元**：依 TIPO 資安政策，特定字元/符號無法用於檢索條件，使用會回「資安禁用字元」錯誤。

---

## 10. 檢索式組裝範式 (AI 產生檢索式時的模板)

大型 landscape 召回式，欄位化 + 布林 + 日期 + 跨欄位排除：

```
(radar or mmwave or "millimeter wave" or 毫米波)@TI,AB
  and (fall or "vital sign" or heartbeat or 心跳 or 跌倒)@TI,AB,CL
  not (vehicle or automotive or 車輛)@TI
  and ID=20180101:20231231
```

- **欄位限定**：每個同義詞群用 `(...)@TI,AB` 綁定欄位，比裸關鍵字精準。
- **跨欄位排除**：`not (...)@TI` 只排 TI 出現的雜訊，不誤殺 AB/CL 有效命中。
- **日期限縮**：`and ID=...` 併入。
- **國別限縮**：資料庫別 (TWA/USA/CNA…) 走 `patDB` 參數，不在檢索式字串內。

## 11. 與現有 MCP tool 的關係 (落地紀律)

- 現行 `patent_search` / `patent_bulk(source="gpss")` 走 **API 端點** (`gpss_api` REST)，keyword 目前塞單一 `TI/AB=` 欄位，**未用**本文的欄位化括號布林全集 → 表達力受限 + 更易撞 condition-length 牆。
- **人類登入路徑** (gpss3 網頁) 已有爬蟲基礎設施 (`patents.py`：Cloudflare cf_clearance 續連 + INFO token + 結果列解析)，目前用於代表圖下載；`_21_1_T` 是通用文字檢索欄位，可塞完整單一檢索式 (推演證實)。
- **在建工具** `gpss_web_search` (plan `patentmcp_gpss-web-boolean-search`)：走人類路徑、吃本文語法、零 API 額度、內建日期/國別限縮、大母數 (>30萬) fail-fast。
